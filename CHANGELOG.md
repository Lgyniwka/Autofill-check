# CHANGELOG — юзерскрипты Autofill-check

Репозиторий: `github.com/Lgyniwka/Autofill-check` (ветка main). Установка/обновление через raw.githubusercontent.com (`@downloadURL/@updateURL`) — CDN отдаёт новую версию с задержкой ~5 мин. После правок: `node --check` обоих файлов, commit+push, версии бампать в `@version`.

## Контекст скриптов

| Скрипт | Контекст |
|---|---|
| **AutoFill.user.js** (AutoFill) | Плавающая панель «Действия» на `tools.sdc.yandex-team.ru/accounting-fleet-works*`: кнопки-пресеты работ (QR, слив логов, ППР, жгут микрофона, флажок, жгуты АКБ, рессоры), оформление работы в поле «Добавить работы», комментарий родителю (`ST_HELPER_*`). Режимы форм: заказ запчастей (`forms.yandex-team.ru/surveys/154795|13693051`, новое окно по GET-параметрам `st_location/st_location_id/st_preset/st_qty`) и осмотр ППР (`/surveys/13691922`, фото по рукопожатию `AF_PPR_READY`/`ST_PPR_DATA`, `AF_PPR_DONE`) |
| **Self_check.user.js** (ST-Ticket-Self-Check) | Панель «Self check» на странице тикета SDCFLEETOPS (tools.sdc): проверки тикета, API Стартрека `st-api.yandex-team.ru` (GM_xmlhttpRequest + OAuth-токен), переходы статусов (всегда «Передать механикам», резолюция fixed в body), заказ запчастей (открытие формы в новом окне + `AF_ORDER_DONE`), ППР-флоу (калибровочные подтиケット: авто-оформление работы через `st_autowork=calibration`, закрытие), консольная утилита `ST_LIST_COMPONENTS` |
| **Rover ID Switcher** | Поле «ID» (Ctrl+Shift+I — фокус): на `tools.sdc/rovers{,-old}` уходит на `/rovers…/aXXX/maintenance`, на `aNNN.launcher.sdc.yandex-team.ru` меняет поддомен `a<id>.launcher…` (путь сохраняется) |
| **QuickBase.user.js** | Панель базы знаний (кнопка-ровер, Cmd+Ё): инструкции, коды дефектов, MCU, поиск открытых работ по роботу через tools.sdc API, кружки приоритета через Startrek API + OAuth |
| **WifiQR.user.js** | На странице лаунчера ровера (launcher.sdc): читает логи SSID/пароль, генерирует QR офлайн (встроенная qrcodejs), кнопки копирования |

Общие договорённости: «закрываем чисто скриптом» — подпись «Платон🧑🏽‍✈️» в комментариях не используется; дефект по умолчанию '0' (флажок BD-02, рессоры CH-01…CH-05 с панели); переход «Обработан» — всегда «Передать механикам» (не электрикам: электрики ставят тег electric, механики — Meh); «Это СК»: Да у mic/АКБ, Нет у рессор и флажка; тег `speed_one` в «Параметрах» — у рессор всегда.
